# Connect Pond

1. Open Pond on this Mac. If you don't have it yet, [download Pond](https://github.com/raphaelsalaja/pond/releases/latest).
2. In Pond, open **Settings → General → Raycast**.
3. Choose **Copy Token**, then paste it into **Local API Token**.

Pond's API only listens on this Mac, at `127.0.0.1`. Leave **Local API URL** as it is unless you changed the port in Pond.
