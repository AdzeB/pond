## New

- Download the browser extension for Chrome or Firefox from the Browser Extension dialog.
- Pond unpacks the extension into your Downloads folder and opens it, ready to load.

## Fixed

- The Chrome extension keeps the same ID after you load it, so it connects to Pond the first time.
