## New

- The command menu searches commands, folders, saved views, and saves together, and still finds them when you mistype.
- Press Tab on a save in the command menu to see its actions, like Add to Folder.
- What's New opens after each update and lists every version you skipped. Open it again from Help > What's New or Settings > General.
- Show Date Published in card captions from View Options > Item Info, or turn it on as a list column.
- The Local API now covers search, related saves, tags, folders, saved views, thumbnails, and edits, so tools like Raycast can work with your library.
- Support Pond from the command menu.

## Improved

- Clicks and toggles sound like physical switches instead of soft tones.
- Command menu previews keep each save's aspect ratio.

## Fixed

- Pond finds Codex and Claude Code installed with Bun on macOS and Linux.
- Sliders and menus follow the pointer when Interface Zoom isn't 100%.
