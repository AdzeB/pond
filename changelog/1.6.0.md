## New

- Create Local API tokens for each tool in Settings > Local API, choose what each one can access, and revoke it at any time.
- Filters, the match-all or match-any choice, and your semantic query stay in place after Pond restarts.

## Improved

- Add Filter groups fields into sections and submenus, with tag and folder pickers that show how many saves each one holds.
- Filter chips name their units and read as phrases, like "≥ 3 Stars", "Width ≥ 1,080px", and "Saved Past Week".
- Source and account chips show their brand icons, and Save View and Clear Filters are icon buttons with tooltips.

## Fixed

- Connecting Are.na opens the Are.na sign-in page.
- Connecting a source tells you when your browser is signed out instead of waiting with no feedback.
- The app icon you choose stays on Pond after it quits, so the Dock and Finder keep showing it.
- A valid Local API token keeps working while Pond blocks repeated wrong tokens.
- Filtering by Font, Title, Camera, or Lens no longer breaks the view.
