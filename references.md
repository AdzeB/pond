# References

An alphabetized APA 7 reference list for sources cited in or influential to Pond.
Each entry has a stable anchor for author–date citations. Entries sharing an author
and year use letter suffixes. Titles or bracketed descriptions stand in for missing
authors or unavailable titles; `n.d.` means no verified publication date.

The [influence index](docs/references/influences.md) explains product decisions and
preserves personal credits. The [inventory](docs/references/inventory.md) retains
package versions, runtime tools, models, assets, and platform context. The
[research record](docs/references/README.md) connects those sources to the product.
Follow the [references standard](docs/contributing/references-standard.md).

Historical provenance is incomplete. Most inherited metadata remains provisional.
Inclusion is attribution, not endorsement or proof of historical use. Package
version ranges are in the inventory, not asserted as publication versions here.
