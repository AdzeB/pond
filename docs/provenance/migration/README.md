# Provenance migration evidence

These files preserve Pond's pre-Provenance bibliography, influence index,
inventory, and research workflow exactly as they existed at migration time.
They are historical evidence, not editable source records.

The migration carried 355 sources and 452 relationships into the authoritative
record under [`.provenance/sources/`](../../../.provenance/sources). Current
generated views live in [`docs/provenance/generated/`](../generated/).

Do not add new entries here. Update the entity `source.md` and run
`pnpm provenance:generate`.
