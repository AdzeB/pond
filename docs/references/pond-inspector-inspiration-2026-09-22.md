## Design question

How should Pond organize asset properties, source context, activity, and editable
metadata in a compact desktop inspector without making the panel feel fragmented?

Twenty distinct results were visually inspected from the Cosmos Elements search.
Inspection was limited to visible previews and element pages. “Uploaded by” records
the visible Cosmos uploader and may not identify the original designer. Original
source links and reuse terms were unavailable. No assets or code were copied.

## Direction

Use one persistent, narrow inspector that follows Library selection. Keep preview,
editable fields, tags, and folders above the metadata. Merge rating, dimensions,
size, type, file facts, and dates into one aligned Properties definition list.
Retain Source and Activity as separate peer sections. Use restrained section
dividers and contextual menus for secondary actions. Keep Export last.

The strongest references are 4, 5, 9, 13, and 15. Together they support a narrow
desktop inspector, compact technical rows, consistent group rhythm, a stable
three-pane Library structure, and quiet light-theme density.
