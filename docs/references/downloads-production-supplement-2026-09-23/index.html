Pond / Production download references / 23 September 2026

Downloads should lead the merged workspace.

Five additional interfaces show the same structure at different scales: state navigation, a durable list, row-level progress, contextual actions, and details that appear only when needed.

Direction The merged destination can be named Sources, but its default view should be the download queue and history. Source, Account, and Watch become filters and management context around that list.

Free Download Manager · desktop queue ↗

Official product screenshot · macOS

Observed

The list remains primary while state and type filters stay close by. A selected transfer exposes source, destination, size, and activity without expanding every row.

Apply

Keep Pond’s center pane dense. Put only name, source, stage, progress, and result in the table; move URL, local path, timestamps, and diagnostics into the inspector.

Creator and publisher: Free Download Manager project.

Motrix · state-led navigation ↗

Official product screenshot · desktop

Observed

Task states form the navigation model, while progress, speed, remaining time, and row actions stay together. Active work is easy to scan without opening a separate dashboard.

Apply

Place All, Active, Waiting, Failed, and Complete above Source filters in the rail. State should be the first way users narrow the table.

Creator and publisher: Motrix project.

Chrome · durable history ↗

User-supplied screenshot on Google Chrome Help Community

Observed

Search and date groups make a long history navigable. Each completed item keeps its filename, origin, reveal action, and a separate control for removing only the history entry.

Apply

Group older Pond downloads by day after active items. Keep Remove from history distinct from Delete file, and make Reveal in Finder the completed row’s main action.

Screenshot uploader: Google Chrome Help Community participant. Interface creator: Google Chrome team.

Downloader Desktop · batch operations ↗

Official repository screenshot · open-source desktop app

Observed

Checkbox selection and a shared toolbar let people start, pause, stop, or remove several transfers. Failure reasons and per-connection progress move into a details view.

Apply

Use selection-driven actions in Pond’s Downloads table. Scope the toolbar to eligible rows and report mixed results when a batch includes incompatible states.

Creator and publisher: bezzad / Downloader.Desktop contributors.

Aloha Browser · compact history ↗

Official knowledge-base screenshot · mobile

Observed

A small screen keeps search, one global cleanup action, a date heading, and the file list. The reduced layout confirms which controls remain essential when space collapses.

Apply

On narrow Pond windows, collapse the Source rail and inspector before removing search, status, filenames, or completed-file actions.

Creator and publisher: Aloha Browser.

What this adds to the merge

  1. Open on All Downloads, with active and waiting work pinned above dated history.
  2. Filter first by state, then by Source, Account, or Watch.
  3. Show progress inside the row and full transfer facts in the inspector.
  4. Expose batch controls only after selection.
  5. Keep history removal separate from deleting the downloaded file.
