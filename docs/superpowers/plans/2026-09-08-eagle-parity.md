## Acceptance evidence

- Native SQLite tests discover folder matches beyond 250 hydrated rows and 500 global keyword hits, page all 1,200 IDs without duplicates, validate cursor scope/revision/order, annotation indexing and local calendar-day matching. Full-schema FTS triggers add and remove results after imports and edits to titles, tags, notes, image comments, video notes, text in images and transcripts.
- Delayed response tests reject obsolete query results and obsolete Select All, preserve loaded extent on refresh, and surface errors instead of false empty results.
- Logical navigation tests exercise multiple unloaded pages and abandon a reveal when query scope changes.
- Isolated built-app media fixtures verify Smart Folder dialog, image zoom, crop copies without changed originals, GIF frames, video loops/stepping at 24/30/60 CFR, and detached controls.
- Browser fixture QA verifies currentSrc/resolution filtering, literal text handling, cancel/restore, scaled region cropping, and refusing to capture a different tab after a switch.
- Filesystem fixtures cover existing filename collisions, every original including nested archive/zero-byte package files, repeated import identity, damaged packages/path escapes, stable watched files/retries, metadata merging and recovery journals.
- Built-app scale testing found and prompted fixes for loaded-only sidebar counts, note-cover requests missing a default, and imported tags missing registry entries.

## Performance evidence

See [built-app measurements](../../research/2026-09-08-gallery-performance.md) and [query-engine measurements](../../research/2026-09-08-query-performance.json).

The built-app run used a 48 GiB M4 Max and a populated index, fresh Chromium profiles, and real repeated PNG/GIF/MP4/note fixtures. At 100k, one startup sample reached mounted cards plus a decoded image in 1,095 ms; warm first-page query plus row-hydration IPC measured p95 105.7 ms for folders and 156.0 ms for keywords. These measurements exclude OS process creation, cold filesystem cache, debounce and post-query paint. They are not the requested signed-package/16 GiB gate and are not measured Eagle timings.

The reusable harness now also measures keyword debounce through renderer paint and gallery frame intervals. One 1k unsigned follow-up on the same 48 GiB M4 Max measured 174.7 ms from Electron text insertion through matching-card paint. Programmatic scrolling kept 354 of 356 frames, or 99.44%, within 16.67 ms; frame p95 was 9.3 ms and the maximum was 25.1 ms. This validates the instrumentation only. It is not the required 10k/100k, signed-package, 16 GiB result.

Proposed targets remain: feedback p95 50 ms; warm folder 150/300 ms at 10k/100k; keyword including debounce 200/400 ms; cached preview 150 ms; cold launch 2/3 s; 95% scrolling frames within 16.7 ms. Compare capture twenty, classify fifty, nested Smart Folder, old-reference search, video inspection and project export with Eagle on identical assets/hardware.

## Verification status

Focused tests run throughout implementation. The final host `pnpm check` run passed 1,859 desktop tests with 64 skipped, including native-ABI and other environment-sensitive tests. The AI retrieval suite passed all nine tests, including a regression asserting that a 500-result request ranks 4,000 dense candidates. A separate Electron Node run across all native-SQLite suites passed 55 tests in ten files, with the opt-in benchmark skipped. The native run includes full-schema search refresh coverage for imports and searchable metadata edits. The final shared shortcut, native-menu, library-link, original-file manifest, retrieval, and measurement-harness changes are included in these runs.

`pnpm build` passed all five bundle budgets: main 2,476.6/2,539.1 KiB, renderer 4,523.7/4,785.2 KiB, website 459.1/488.3 KiB, extension 1,157.0/1,220.7 KiB, worker 113.8/146.5 KiB. The final build includes those changes. `git diff --check` also passed.

Additional evidence: [authenticated asset capture](../../research/2026-09-08-authenticated-asset-runtime.md), [backup and fresh-index restore](../../research/2026-09-08-backup-restore-runtime.md), and [capture/portability implementation](../../research/2026-09-08-capture-portability-implementation.md).
